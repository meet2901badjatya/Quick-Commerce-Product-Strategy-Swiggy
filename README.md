# Swiggy Instamart Product Strategy: Improving Average Order Value (AOV)

## Project Overview
This repository contains a product case study focused on Swiggy Instamart, a leading quick commerce platform in India operating in over 600+ cities[cite: 23]. Developed by Meet Badjatya, the goal of this project is to propose data-driven product features and strategies designed specifically to increase Swiggy Instamart's Average Order Value (AOV), which currently sits around ₹400[cite: 22, 23].

## The Business Problem
Despite rapid market growth—projected to reach 60.6 million users and $9.95B in revenue by 2029[cite: 24]—quick commerce operates on extremely thin margins. To improve profitability against competitors like Blinkit and Zepto, platforms must increase the basket size and transaction value per order[cite: 23]. This project identifies user pain points and leverages behavior patterns to suggest scalable features that encourage customers to add more items to their carts and commit to recurring purchases.

## Key Insights & Market Analysis
* **Market Sizing:** The Indian Q-Commerce market's Average Revenue per User (ARPU) is estimated at $127.70, with a user penetration rate projected to rise to 4.0% by 2029[cite: 24].
* **Competitor Benchmarking:** Swiggy Instamart's AOV is ₹400, while competitors like Blinkit see ₹522-₹553[cite: 23]. Instamart offers a 10% average discount, 10-20 minute delivery times, and operates via a dark store model across 18 cities[cite: 23].
* **Target Personas:** 
    * *Riya (20, Student):* Highly price-sensitive, demands late-night deliveries, prone to spontaneous small purchases[cite: 25].
    * *Mayank (27, Corporate):* Values health/fitness, willing to pay a premium for quick organic deliveries[cite: 25].
    * *Jaya (35, Mother):* Focuses on premium, bulk household items and high-quality brands for her family[cite: 25].

## Proposed Product Features
1. **Curated Bundles & Meal Kits:** Themed packages (e.g., Movie Night Packs, Study Snacks) and meal kits (e.g., Sushi Kit) to encourage cross-selling[cite: 26].
2. **Subscription Services:** Automated weekly or monthly deliveries for staples like milk, health supplements, and household essentials[cite: 26].
3. **Dynamic Pricing:** Real-time pricing adjustments based on demand and customer browsing habits to create personalized discounts[cite: 26].
4. **Personalized Shopping Recommendations:** AI-driven suggestions based on past behavior to increase basket size[cite: 26].
5. **Shopping Lists & Auto-Reorder:** A feature integrated into the app's 'Reorder' section allowing users to create custom lists (e.g., "Party List", "Cleaning") for one-tap bulk purchasing[cite: 27].

## Feature Prioritization (R.I.C.E. Framework)
Features were ranked based on Reach, Impact, Confidence, and Effort:
1. **Curated Bundles & Packs:** Score 89.6 (Highest priority)[cite: 28].
2. **Personalized Recommendations:** Score 82.3[cite: 28].
3. **Shopping Lists:** Score 81.0[cite: 28].
4. **Subscription Services:** Score 56.0[cite: 28].
5. **Dynamic Pricing:** Score 36.75[cite: 28].
